# Outils Chase (Tracker)

- **`scripts/chase-tracker.js`** : à chaque run, Chase (1) vérifie les positions fermées via ASTER, met à jour les outcomes ; (2) **annule les ordres obsolètes** (prix trop éloigné du mark, tendance plus bonne après loss, orphelins sans position) pour libérer la marge — seuil `CHASE_STALE_ORDER_PCT` (défaut 10 %) ; (3) synchronise les idées APPROVED vers data/tracker/outcomes/ ; (4) génère les post-mortems pour les outcomes complétés ; (5) écrit le feedback par agent dans data/tracker/feedback/ et data/dashboard/chase_feedback.json ; (6) lance le **diagnostic des pertes** (scripts/chase-loss-diagnostic.js) → data/dashboard/chase_loss_diagnostic.json et .md (causes : signaux, timing, conditions marché). ASTER requis pour sync positions et annulation d’ordres.
- **Post-mortem Tibo** : Chase lit `data/dashboard/tibo_report.json` et `data/dashboard/executed_orders.json` (ordres placés, TP en attente) pour enrichir les post-mortems et le feedback Tibo (qualité d’exécution, marge).
- Fichiers outcome : data/tracker/outcomes/{trade_id}.json (outcome, exit_price, closed_at, note). Remplis automatiquement par Chase via ASTER, ou manuellement / via `sync-closed-outcomes-and-chase.js` si besoin.
- Les agents (TECHNICALS, SMART_MONEY, etc.) lisent data/tracker/feedback/{agent}.md ou chase_feedback.json pour s’améliorer.
