# Tâches Intel (Daphnée)

1. **X (Twitter)** : interroger l’API X (recherche recent) sur crypto/bitcoin, extraire thèmes et tendances du jour, produire une ou plusieurs Trend Cards (titre, résumé, source X).
2. **YouTube** : **scrape par jour** — top 30–50 vidéos crypto (veille si API Google : `order=date` + `publishedAfter`). Requête « crypto bitcoin news ». **Une carte n’est créée que si un transcript est disponible.** Daphnée **classe** chaque vidéo d’après le transcript : **rejeté** uniquement si placement crypto (pousser une crypto/token) ou contenu insuffisant — pas pour lien d’affiliation exchange/app ni code promo générique. Sinon **borderline** (utile). Config : `dashboard/config/intel_youtube_filter.json` (phrases shill, `min_transcript_length`). Le dashboard affiche d’abord la **Cryptosphère YouTube** (vidéos utiles), puis les vidéos écartées en repliable. Transcript : skill youtube-watcher (yt-dlp), npm youtube-transcript, yt-dlp en direct. Env : `INTEL_YOUTUBE_VIDEOS_PER_DAY` (50), `INTEL_YOUTUBE_MAX_CARDS` (30).
3. **Calendrier économique (investing.com)** : vérifier le calendrier économique traditionnel (https://www.investing.com/economic-calendar) pour les dates/heures clés (Fed, NFP, CPI, PMI, etc.) ; garder les événements en mémoire (`data/dashboard/intel/economic_calendar.json`) ; après publication, vérifier les chiffres publiés (actual vs forecast/previous) ; intégrer les événements macro aux Trend Cards (carte « Macro ») pour l’orchestrateur et les tendances.
4. **CryptoDaily** : exécuter `cryptodaily-news.js` pour récupérer les actualités crypto du jour (API RapidAPI CryptoDaily) et écrire `cryptodaily_news.json`. intel-scan lit ce fichier et ajoute une Trend Card « Actualités crypto (CryptoDaily) » si des items sont présents.
5. **Reddit** : exécuter `reddit-intel.js` pour récupérer les subreddits similaires (cryptocurrency, bitcoin, ethereum, etc.) via RapidAPI Reddit (getSimilarSubreddits) et écrire `reddit_intel.json`. intel-scan lit ce fichier et ajoute une Trend Card « Reddit — subreddits crypto similaires ».
6. **Sortie** : écrire `data/dashboard/intel/trend_cards.json` (date, liste de cartes avec source, title, summary, url, classification), `data/dashboard/intel/economic_calendar.json` (événements à venir + actuals après publication), `data/dashboard/intel/cryptodaily_news.json` (actualités CryptoDaily) et `data/dashboard/intel/reddit_intel.json` (subreddits Reddit). Le dashboard et le BOSS consomment ces fichiers.
