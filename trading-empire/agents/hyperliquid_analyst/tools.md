# Outils Hyperliquid Analyst

- **Lecture** : `data/dashboard/hyperliquid_analyst_report.json` (rapport précédent, inclut `context_news`, `context_intel`, `context_macro`, `context_hip3_news`), `data/hyperliquid/commodities_meta.json` (actifs tokenisés main + **HIP-3**), `data/hyperliquid/hip3_dexes.json`, `data/hyperliquid/leading_vaults_*.json`, `data/dashboard/intel/trend_cards.json`, `data/dashboard/intel/economic_calendar.json`, `data/dashboard/intel/news_scan_report.json` (Parvati — catalysts et RSS), `dashboard/config/hyperliquid_analyst_sources.json` (mots-clés et flux RSS HIP-3 : or/métaux, actions, énergie), `data/signals/technicals/`, `docs/HYPERLIQUID_COMMODITIES.md`, `rules/risk_rules.md`.
- **Écriture** : `data/dashboard/hyperliquid_analyst_report.json` (rapport avec recommandations), optionnellement `data/dashboard/agent_profit_suggestions.json` pour pistes BOSS.
- **Scripts** (à appeler depuis la racine du workspace `~/.openclaw/workspace`) :
  - `node TradeEmpire/trading-empire/scripts/fetch-hyperliquid-top.js` — récupère les leading vaults HL (déjà en place).
  - `node TradeEmpire/trading-empire/scripts/hyperliquid-commodities-scan.js` — appelle `perpDexs` et `allPerpMetas` pour récupérer **tous les perp (main + HIP-3)** ; filtre or, pétrole, matières premières, actions ; écrit `data/hyperliquid/commodities_meta.json` et `hip3_dexes.json`.
  - `node TradeEmpire/trading-empire/scripts/hyperliquid-analyst-trend.js` — génère le rapport avec **toutes les sources** : commodities_meta, Parvati (news_scan_report → context_news), Intel (trend_cards → context_intel), calendrier économique (context_macro), flux RSS HIP-3 (Kitco, Yahoo Finance → context_hip3_news). À lancer après commodities-scan (et idéalement après run-morning pour avoir Parvati/Intel à jour).
- **API Hyperliquid** : `https://api.hyperliquid.xyz/info` (POST, body JSON : `{ "type": "meta" }`, `{ "type": "metaAndAssetCtxs" }`). Connexion signée si besoin : `HYPERLIQUID_WALLET`, `HYPERLIQUID_SECRET` dans `workspace/.env` (voir `docs/API_KEYS.md`).
- **Pas d’exécution d’ordres** : l’agent produit des recommandations ; les ordres sont passés via le flux décisions → Risk Journal → Executor (Tibo) ou un workflow dédié HL à définir.
